# Mood Based Music and Activity Recommender

## Project Description

The Mood Based Music and Activity Recommender is an AI/ML-based web application that recommends music and activities according to the user's mood.

## Features

- Mood selection
- Mood prediction
- Music recommendations
- Activity recommendations
- Motivational messages
- Simple and user-friendly interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- Pandas
- Scikit-learn
- Machine Learning

## How to Run

1. Install Python.
2. Install the required packages:

pip install -r requirements.txt

3. Run the Flask application:

python app.py

4. Open the local URL shown in the terminal.
